# Roadmap

Upcoming ShareKit features. Scope and version numbers may change; release dates are not yet scheduled.

| Version | Features |
| --- | --- |
| 0.6.0 | Native Windows sharing for JVM desktop |
| 0.7.0 | File and image sharing, followed by multiple-file support |
| 0.8.0 | Optional Compose integration and interactive samples |
| 1.0.0 | Stable API, compatibility policy, and migration guide |

See the [changelog](CHANGELOG.md) for release history.
